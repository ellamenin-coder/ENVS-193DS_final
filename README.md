# ENVS-193DS_Final

Spring 2026

## General Information

This repo provides information on research writing (making suggestions and
rewriting others' work), examples of linear regression with multiple variables,
and comparing and contrasting affective and exploratory visualizations that I
have created over the quarter.

The personal data in this repo examines the relationship between my daily water 
intake (liters) and sickness. It was collected myself, and in part 3 of this
work, I analyze the data how I find fit.

## Data and file information

There is a 'data' folder in which my personal data is stored.

There is a 'code' folder in which all of my code for the visualizations is
stored.
